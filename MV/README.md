# MV

ESSENCE is a music video being cut here, about the essence of humanity in machines. The screening page is [index.html](index.html). The picture and the rules for the next pass are in [ART.md](ART.md).

Open footage, an original score, one frame. The film on the page is movement I. The length we are cutting toward is 3:00.

Four finished 90-second samples sit beside it, same frame, same kind of night, different cities and decades. Each has its own page and its own score.

- [KOWLOON](kowloon/index.html) — Hong Kong, rain on the glass
- [NINETY](ninety/index.html) — a game still running
- [CHROME](chrome/index.html) — nineteen eighty, neon and a hand
- [PHOSPHOR](phosphor/index.html) — the tube draws the night

`python3 build_samples.py` from this folder recuts them. Rushes stay in `rushes/` and are not committed.
